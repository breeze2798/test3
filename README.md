# 화음으로 노래를 꾸며요

초등 6학년을 위한 2차시 웹 음악 학습지입니다. HTML, CSS, JavaScript만 사용하는 정적 사이트로, 서버 계정이나 외부 건반 앱 없이 작동합니다.

## 실행

`index.html`을 최신 Edge, Chrome, Safari에서 엽니다. 파일을 직접 열 때도 소리를 사용할 수 있으며, 브라우저 정책에 따라 로컬 답안 저장은 제한될 수 있습니다. 안정적인 저장에는 정적 웹 서버 사용을 권장합니다.

Node.js가 있다면 저장소에서 `node server.mjs`를 실행하고 `http://127.0.0.1:8765`를 엽니다. 종료는 Ctrl+C입니다. 설치나 빌드가 필요하지 않습니다. 소리는 사용자가 듣기 버튼을 누른 뒤 시작됩니다.

## 수업 구성

1. 화음 만나기: 한 음과 화음 비교, 다장조 주요 3화음, 터치 건반, 구성음 확인.
2. 반주 만들기: 자체 제작한 4/4박자 8마디 연습 가락에 마디별 화음을 선택하고 비교·수정.
3. 교과서에 적용하기: 천재교과서·미래엔·비상교육 중 선택하고 곡명, 쪽수, 마디 범위 기록. 실제 교과서를 참조하며 화음 반주만 재생.

교과서 활동은 **다장조·4/4박자이며 주요 3화음으로 반주 가능한 8마디**를 교사가 사전에 선정합니다. 교과서 악보나 음원을 복제하거나 내장하지 않았습니다. 교과서의 다른 조·박자에는 그대로 적용하지 않습니다.

연습곡 ‘한 걸음 산책’은 이 프로젝트에서 만든 가락입니다. 네 음은 각각 한 박입니다. 예시 반주: Ⅰ–Ⅳ–Ⅰ–Ⅴ–Ⅳ–Ⅰ–Ⅴ–Ⅰ. 예시 외의 선택도 직접 듣고 설명하도록 지도합니다. 반주에서는 자연스러운 연결을 위해 구성음의 옥타브 배치를 조정합니다.

## 답안과 인쇄

- 이름과 답안은 `harmony-lab-v1` 키로 현재 브라우저의 localStorage에만 저장됩니다. 외부 서버 전송이나 교사 수집 기능은 없습니다.
- ‘답안 초기화’는 확인 후 이 학습지의 답안을 초기화합니다. 기기를 함께 사용하면 학생별로 인쇄한 뒤 초기화해 주세요.
- ‘학습지 인쇄’는 화면에서 숨겨진 차시까지 모두 포함합니다. **A4, 배율 100%, 브라우저 머리글/바닥글 끄기**를 권장합니다. 인쇄 대상에서 ‘PDF로 저장’을 선택할 수 있습니다.
- 기본 학생용은 3쪽으로 설계했습니다. 매우 긴 답안은 잘리지 않도록 추가 페이지로 이어질 수 있습니다. 교사용 안내는 별도로 인쇄합니다.

## 파일

- `index.html`: 학생용 3단계와 교사용 안내
- `style.css`: 반응형 화면과 인쇄 스타일
- `app.js`: Web Audio 음원, 재생 제어, 답안 저장
- `server.mjs`: 선택적으로 사용하는 로컬 미리보기 서버
- `tests.mjs`: DOM과 모의 오디오를 이용한 기능 검사 (`npm install` 후 `npm test`)

## 배포

정적 호스팅에 위 세 웹 파일을 그대로 올리면 됩니다. 이 작업에서는 GitHub Pages나 별도 호스팅을 자동 활성화하지 않습니다.

## 검증 범위

문법·HTML 구조·답안 저장/복원·빈 화음 검증·오디오 예약/정지 로직을 자동 검사합니다. 모의 DOM/오디오 검사는 실제 기기의 청취 및 브라우저 인쇄 검사를 대신하지 않습니다. 현재 작업 환경에서 브라우저 조작 승인이 거부되어 실제 브라우저의 화면, 오디오 출력, A4 페이지 수는 확인하지 못했습니다.
